# Convert a string to lowercase

Write an extension function called `toLowercaseString` that takes a string and returns a lowercase version.

**Hint:** Use the [`.lowercase()`](https://kotlinlang.org/api/latest/jvm/stdlib/kotlin.text/lowercase.html) function for the `String` type.
