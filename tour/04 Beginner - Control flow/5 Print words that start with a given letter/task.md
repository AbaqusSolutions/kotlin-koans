# Print words that start with a given letter

You have a list of words. Use `for` and `if` to print only the words that start with the letter `l`.

**Hint:** Use the [`.startsWith()`](https://kotlinlang.org/api/latest/jvm/stdlib/kotlin.text/starts-with.html) function for `String` type.
